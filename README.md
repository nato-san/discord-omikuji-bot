# Crypto おみくじ Bot (Nansen Hackathon 提出用)

## 概要 (Overview)
Discord上で「おみくじ」と発言すると、今日の運勢と一緒に、**Nansen API** を活用して「今まさにアツい仮想通貨」を教えてくれるエンタメ性のあるBotです。

大きな特徴として、**「大吉」を引くと今一番熱狂している(Volume/MCAP比率の高い)エリートコイン**が紹介され、逆に「凶」を引くとギャンブル性の高い魔界コインが選ばれたり、「大凶」の際はそもそも購入を見送るよう（見送り一択の）アドバイスがされるなど、引いたおみくじの運勢とNansenデータによるコインの実態が完全に連動しています！

## 使い方 (Usage)
1. Botが参加しているテキストチャンネルで `おみくじ` と入力します。
2. 運勢とともに、Nansenから取得した「🏷️ Nansen AIラベル予想」「スマートマネー温度計」「流動性」「時価総額」などの完全なオンチェーン情報が表示されます。

**(※ このおみくじ結果は投資助言ではなくエンターテイメントです。投資判断は自己責任でお願いします！)**

## 開発環境・セットアップ (Setup)
- `npm install` または `npm install discord.js axios dotenv` で必要なものをインストールします。
- 手元で動かす場合は、`.env` ファイルに以下を設定して起動します。（※ `.env` ファイルはAPIキーが書かれているため、絶対にGitHubなどの公開場所にアップロードしないでください）
  - `DISCORD_TOKEN`
  - `NANSEN_API_KEY`
  - (任意) `NANSEN_CHAINS` (例: `solana,base`)
- `node index.js` で起動します。

**【GitHubへ公開して利用される方へ】**
本リポジトリには `.gitignore` が含まれており、`.env` が誤ってアップロードされないよう保護しています。
もしGitHub Actionsなどのクラウド環境からBotを起動させる場合は、[GitHubリポジトリの Settings -> Secrets and variables -> Actions] の画面から、`DISCORD_TOKEN` と `NANSEN_API_KEY` を登録（暗号化）して使用してください。

## AI 利用の開示 (AI Disclosure)

本プロジェクトは大会のルールに基づき、以下のAIを利用して開発・運用されています。

### 1. 開発AI (Development AI)
- **使用ツール:** Cursor / Antigravity (Google Deepmind)
- **使用箇所:** 
  - プロジェクト全体の設計とアイデア出し
  - Node.js (Discord.js, Axios) を使った API連携コードの作成
  - Discord 埋め込みメッセージ（Embed）のデザインと構築

### 2. ランタイムAI (Runtime AI)
- **使用モデル:** なし (Not Used)
  - ※ 本Botの実行中（ランタイム）にはAIモデルによる動的な文章生成等は行っていません。乱数と条件分岐、および Nansen API から取得した確定データのみを用いて計算・動作しています。
  - **ガードレール・フォールバック動作:** APIエラー時や情報が取得できなかった場合は、無理に処理を進めず固定のテキストメッセージ（「候補が見つからなかったよ」等）を返す安全設計（フォールバック）になっています。
